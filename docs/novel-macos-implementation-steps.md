# 阅栖 macOS 小说 App：详细开发步骤

日期：2026-10-15。本文是可交给后续 Codex 逐项执行的实施计划，**MAC-01、01A、MAC-02、MAC-06、MAC-03、MAC-16、MAC-04、MAC-05、MAC-07与MAC-08已完成，TXT/EPUB已有基础阅读，完整排版仍待实现**。项目显示名保持“阅读软件”，小说 App 暂定“阅栖”。功能基线见 [完整功能方案](novel-macos-plan.md)，任务状态以 [MAC backlog](novel-macos-backlog.md)为准。

## 交付范围与执行方式

先做当前 Apple Silicon Mac 上可安装、自用的中文小说 App；覆盖本地 TXT/EPUB、书架、排版与进度、中文搜索、书签笔记、系统听书、备份、桌面交互，以及内置/导入的普通与18+免费书源、在线搜索阅读、下载与追更。无登录、无后端也可使用本地功能。

一套小说 Flutter 工程保留 macOS/Windows/Android/iOS 宿主。小说与漫画仍是两个独立 App，后端仍为后续可选的 Spring Boot 模块化单体。首版不需要先部署 MySQL/Redis，不把漫画代码混入小说工程。

一个开发批次只领取一个 MAC 主任务，交付一条可验证路径；先记录“进行中”，完成后更新任务、接口、依赖和验证证据。下面的步骤是推荐顺序，不创建另一套任务编号。技术小样可以提前做，但主任务只有全部验收通过后才完成。

## 代码落点与设计基线

以下路径/类型按任务逐步实现。MAC-01已有lib/main.dart、test、四端宿主与reader_core最小包；MAC-02已建立lib/app、features和最小平台端口；MAC-06增加独立tool/mac06探针，MAC-03已接入本地SQLite/文件与位置协议。所有产品业务在小说/client，不按手机/PC或开发/生产复制代码。

| 位置 | 实现职责 |
|---|---|
| 小说/client/lib/app | 启动、依赖装配、路由、主题、全局生命周期 |
| 小说/client/lib/features | library、importer、reader、search、annotations、speech、sources、downloads、backup、statistics、settings；每个feature按domain/application/infrastructure/presentation需要分层 |
| 小说/client/lib/infrastructure | App数据库装配、文档注册、任务调度、脱敏诊断 |
| 小说/client/macos | Runner、菜单/文件打开、权限、必要的原生桥接；只放macOS实现 |
| 小说/client/android、ios、windows | 同一Flutter业务的未来宿主适配，生成后逐端核验 |
| packages/reader_core | 共用ID、语言、分级、错误值；不放小说排版 |
| packages/reader_storage | 存储/迁移和缓存基础；小说具体表归小说工程 |
| packages/platform_services | FileAccess、SecureStore、SpeechService、WindowIntegration、Lifecycle等端口与平台实现 |
| packages/novel_sources | BookSource、来源注册、规则解释子集、HTTP权限和适配器 |
| 小说/client/test、integration_test | 单元/组件/本地集成测试，公共端点不作为CI依赖 |
| fixtures | 小型自产中文样本与生成器，记录出处；不提交私人书籍或成人正文 |

MAC-02采用SDK装配/路由；MAC-03采用精确sqlite3 3.7.1后台连接与显式SQL，详见ADR-0006。Riverpod/go_router/Drift仍为未引入候选，不冒充已用依赖。EPUB与TTS先做小样再定具体绑定。环境事实和维护者依据见 [环境核验](development-environment.md)。不一次性初始化所有共享包和服务端空工程。

页面方案：左侧导航包括书架、在线搜书、来源、下载、笔记、统计、设置；阅读页面可收起侧栏，带目录/笔记面板。成人收藏为独立分组，入口受资格/隐私锁控制，不能被搜索开关误删。初版单主窗口，路由参数只携带书籍/章节ID。手机后续改导航布局，共享同一用例与数据协议。

## 00：继续核验真实来源

对应MAC-18，依赖MAC-00。本步仍进行中；用户已另行授权提前开展01A设计。已有[单源续验](source-step00-2026-10-15.md)和五合集证据；2026-10-16改用[“地外文明”特殊区域策略](development-region-policy.md)，不核验具体地区或要求境内网络实测，地区待核不阻塞技术测试与工程。《孔乙己》完整短篇、Gutendex中文目录及官方OPDS有技术证据，内置批准仍0/0，不能改名后冒充来源已通过。

1. 分别建立普通/成人候选矩阵，按中文覆盖、免费范围、官方接入方式、作品/规则许可、年龄、离线与署名逐项筛选。
2. 为候选记录官方链接、日期、版本/修订/hash、额度、样本结果与不允许的能力；当前地区项记skipped_by_user，不做地区专项。可以部分通过或拒绝，不强行凑数。
3. 公开可正常访问的资源可先做安全小样搜索→详情→目录→章节/文档，技术可用性与内置/缓存/分发权限分别记录；需要认证时使用正常流程，不绕过。原始响应不带敏感凭据，仓库只留允许的摘要。
4. 给每个来源形成可用范围：normal/adult/mixed/unknown、free/limited_free/paid/unknown、能力、许可/缓存限制和复核时机；审批范围不能推及整个网站。

交付：docs/verifications记录、批准范围与禁用原因。验收：普通/18+各至少一条真实中文免费路径及证据；未满足则持续进行，完整首版条件未解除。成年规则名、R18字符串、接口HTTP200或用户自行导入都不能单独代表通过。

## 01A：独立视觉设计与原型确认

对应MAC-02-D，依赖MAC-00，当前D1暖纸设计包与可点击原型已获用户明确确认，状态已完成，见[确认记录](design/novel-macos/confirmation-D1.md)；独立范围与确认规则见[UI设计任务](novel-macos-ui-design.md)。排在第01步之后、第02步编码之前，允许提前做设计。

1. 收敛视觉方向与基础规范：明暗主题、字体/色彩/间距、控件与状态，面向macOS中文阅读。
2. 完成主框架、书架、阅读器、在线搜书、来源中心与设置主要页面，以及任务/下载、笔记、统计框架；覆盖常规/窄窗/专注布局与关键空态/错误。

交付：可查看设计稿、可点击原型、样式/组件与交互规范、用户确认记录。验收：主风格、导航布局和关键交互已获用户明确确认；待确认时不得进入第02步编码。此步没有实现App功能。

## 03：提前验证三项技术风险

状态：2026-10-19已完成，见[MAC-06验收](verifications/mac-06-2026-10-19.md)及[EPUB](decisions/0003-mac06-epub-rendering.md)、[检索](decisions/0004-mac06-chinese-search.md)、[TTS](decisions/0005-mac06-system-tts.md)决策。MAC-06正式小样依赖MAC-02；中文索引/TTS只做前置研究，MAC-10/12正式交付仍等待数据/阅读器。整机断网、休眠及生产性能等未通过项已明确留给MAC-07/10/12。

1. EPUB对比受控WebView与Flutter排版：同一自产EPUB的目录、图片、CSS、中文选字、高亮、锚点、搜索/TTS文本映射、窄窗/双栏、四端可替代性、资源隔离和许可证。至少形成一条可用路线，不能把EPUB解析包等同完整阅读器。
2. 中文检索比较SQLite可用tokenizer与受控子串/索引策略；验证简繁原文、单字/短语、标点、emoji和误命中。简繁等价匹配是可选显示/检索层策略，不能改原文ID。
3. TTS在当前Mac上测可用中文语音、离线、暂停/继续、回调偏移单位、切书取消与长时播放。flutter_tts的macOS暂停/标记能力不能凭包名假定，必要时试系统原生桥接。
4. 输出决策记录、样本、限制、失败回退与选定版本，不把需要的核心能力悄悄删为“以后再说”。

交付：后续docs/decisions内的EPUB/检索/TTS决策与小样证据。验收：能解释每条必需功能由什么实现、如何验证，未通过项有明确下一步；不以小样标全App完成。

## 04：本地数据与稳定位置

对应MAC-03，依赖MAC-02。状态：2026-10-20已完成，见[验收](verifications/mac-03-2026-10-20.md)、[ADR-0006](decisions/0006-mac03-local-storage-and-anchors.md)及[存储协议](storage/novel-schema.md)。落点：小说领域模型、App数据库、reader_storage；当前用户可保存自产样本与手动段落位置，通用解析/导入待后续任务。

1. 定义Book、Edition/DocumentRevision、Chapter、Resource、ReadingPosition、ListeningPosition、Bookmark/Annotation、Collection/Tag、SourceBinding、ImportJob、DownloadJob与Settings。正文/图片用文件，SQLite存引用、状态和索引。
2. 导入文件用内容hash识别重复；书名不是唯一键。线上身份用source_id/source_item_id；本地稳定book_id独立于路径，换源不会静默合并内容身份。
3. TXT位置保存文本修订、章节/段落、明确单位的偏移及前后文指纹；EPUB保存spine资源与经MAC-06验证的CFI或结构锚点。统一DocumentAnchor外层携带版本与格式，不用屏幕页码作为持久位置。
4. 规定Dart、原生TTS、EPUB脚本桥接的偏移单位转换，覆盖emoji/组合字符。找不到精确锚点时回退到可解释位置，保留旧锚点/摘录。
5. 定义事务、单写入协调、迁移前备份和失败只读/恢复入口；数据库目录由平台服务取得，不把开发目录硬编码成运行数据目录。先定义未来同步所需revision/墓碑边界，不实现服务器或空转网络outbox。

交付：schema、迁移/位置协议文档与本地Repository。验收：重启恢复、失败事务、旧schema恢复、小说/漫画数据隔离；未知权限不是true。

## 05：分级与独立成人收藏

对应MAC-16，依赖MAC-02/03，贯穿所有后续页面。已完成本步基础，见[验收](verifications/mac-16-2026-10-20.md)与[ADR-0007](decisions/0007-mac16-local-access-and-privacy.md)；尚无原生TTS/窗口/通知或真实来源，后续各表面必须延续门禁。

1. 保存来源原始评级、内部级别、年龄/地区/证据/策略版本；未知和禁止内容不能自动归普通。
2. SearchPreferences.includeAdultSources首次默认为false；搜索资格与已有作品的查看/阅读资格分别判断。成人收藏独立分组，关闭搜索开关不删除或撤销既有阅读许可。
3. App自身仅展示一份“我确认已经成年”声明，主动确认后本机保存，无定期重验，不收集生日/实名/证件；重启或解除隐私锁不重问。未确认不进受限内容，普通阅读可用；确认不自动开成人搜索。来源自身登录/年龄页面按正常流程，当前特殊区域不增加项目地区核验。
4. 隐私锁单独处理目录、详情、封面、笔记、搜索缓存、TTS和通知；资格失效时停播/隐藏，解锁后恢复允许状态。界面锁不声称加密磁盘。

交付：策略服务与受控分组，只有标签的自产fixture。验收：开关OFF仍能按已有权限读收藏；主动锁定/资格失效独立阻断，备份不能恢复成人资格。

## 06：授权与文件导入

对应MAC-04与MAC-13文件部分，依赖MAC-03/02。已完成，见[验收](verifications/mac-04-2026-10-21.md)与[ADR-0008](decisions/0008-mac04-document-import.md)。落点：LocalImporter、DocumentAccess、macOS适配。正文解析分别在步骤07/08继续。

1. 接通文件选择、拖放、批量TXT/EPUB；检查格式/大小、预览标题/编码/导入模式/分级，逐文件显示结果。
