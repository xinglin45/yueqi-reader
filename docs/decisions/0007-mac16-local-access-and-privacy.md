# ADR-0007：本机成年声明、独立搜索偏好与隐私隐藏

日期：2026-10-20。采用，适用MAC-16内部检查点0.0.5+5。沿用已确认D1，不增加地区或身份核验。

## 决策与实际边界

`ContentRating`保留原始评级、general/mature/restricted/unknown/prohibited、来源最低年龄/地区标签、证据与策略版本。schema4新增content_policy；地区核验固定skipped_by_user，来源地区标签仅保存原值。unknown/prohibited不会降为普通；来源自身unknown/loginRequired/ageRequired/paid/expired阻断访问，App声明不替代来源条件。来源allowed必须由当前Repository会话显式核验；数据库里历史allowed在新会话按unknown处理，复制/恢复书库不能单独恢复来源资格。来源最低年龄大于18时，本机成年声明也不能单独放行，须有来源自身allowed资格。

`AccessState`的acknowledged、includeAdultSources、privacyLocked独立。唯一声明是未预勾选的“我确认已经成年”；主动确认后本机保存，无生日/证件/实名、期限或复验。首次搜索偏好false，声明不自动开启搜索；关闭搜索保留已有收藏/阅读资格；解锁不再声明。清除声明立即隐藏并关闭搜索，但不删除收藏。

`AccessController`先同步发布限制，提升权限须等当前意图持久化成功；串行写入与代际避免旧异步授权重新打开门禁。受保护会话作废回调同步执行；搜索有独立取消代际。隐私锁/声明清除/来源资格失效重建当前页面，丢弃预览和侧栏标题；TaskView和Repository各自检查取消/资格，直接阅读路由、位置读取/保存也过门禁。关闭搜索不作废阅读会话。

隐私锁是界面隐藏，不是磁盘加密、密码/PIN认证或抵御能修改本机文件者的安全边界。单主窗口当前无原生TTS、通知、菜单栏/阅读条等表面；只提供统一作废回调并用测试替身验证，后续MAC-09/12/13/17/20必须逐表面注册，不得声称本批已完成这些功能。

## 持久化与备份边界

系统Application Support下，`novel`保存可迁移书库DB/objects，兄弟目录`novel-device/access-v1.json`只保存本机声明/搜索/锁状态，不含身份信息、凭据、书名或正文；本步没有新增插件或系统权限。小文件严格schema/大小校验，暂存flush后rename；损坏、符号链接或读失败按未声明/锁定处理，写失败不发布提升权限。普通阅读不依赖此文件成功。

App可移植备份/同步不得携带设备目录或AccessState，领域协议对导入的访问状态字段一律拒绝；全新书库也清除残留设备声明。复制novel目录到新装配的测试证明不会恢复声明。**MAC-14完整备份/恢复尚未实现**，必须沿用此排除规则；这不承诺防止用户手工复制整个系统资料区或OS整机镜像，也不绑定硬件标识。未引入Keychain来存普通自我声明；未来来源Token/Cookie仍须走系统安全存储。

## 当前产品范围

成人收藏按分级单独查询，已确认且未锁定才取标题。只有用户主动添加的中性“分级测试卡片”，正文只有自产测试说明，没有成人内容。普通书架不混入受保护/未知内容。源码、测试和日志不含真实成人资料或公网请求。

搜索协调器是请求前的筛选/取消边界，生产注册表为空，获准来源仍普通/18+ 0/0。mixed普通路径必须显式声明可靠的源端排除能力；没有该能力则OFF完全不请求。测试适配器只在内存返回自产标签，不证明任何真实来源资格。真正来源协议、缓存、HTTP重试与接入保留MAC-17/19/20。
