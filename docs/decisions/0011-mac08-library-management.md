# ADR-0011：书籍管理、版本化撤销与可恢复文件回收

日期：2026-10-23；状态：采用；任务：第09步MAC-08。沿用D1、Local-first、MAC-04授权、MAC-05/07位置协议与MAC-16分级，不接入新来源或后端。

## 数据和查询

schema7在现有16表上增加book_metadata、shelf_preferences、shelf_actions、file_recycle，共20表；collections增加normal/adult范围，imports增加只读display_name。完整DDL由[导出工具](../../小说/client/tool/mac08/export_schema.dart)从实际SQLite生成，见[schema7](../storage/novel-schema-v7.sql)。已有原件、不可变document修订、门禁与位置不重写；已有位置的更新时间用于回填“在读”与最近阅读。没有把正文、图片字节或设备声明放进新表。

书籍身份仍为随机book_id。同文件由现有digest/格式去重，不按书名或作者合并；同名提示限当前分级范围，供人工辨认。已移出/已回收的同一文件再次导入时明确指向恢复，不静默复活或新建第二本。旧导入无法补得原始文件名时留空，不推测系统路径。

ShelfRepository提供每页50本的有界查询、总数、元数据搜索、格式/状态/收藏/分组筛选及手动序号/标题/作者/最近阅读/加入时间排序。普通、成人和普通最近阅读的偏好分别持久化。最近阅读由实际打开正文触发，不从书架点击次数伪造；读完后再打开保留读完。自动滚动进度与完整排版仍留MAC-09。

合集与标签分别命名，普通/成人范围固定，用户不能把受保护书籍分配到普通标签。每本最多50个自定义归属、每范围最多500个分组；批量归属明确替换自定义选择，成人默认分组保留。停用分组不删书或归属，可点击已停用分组恢复；名称冲突时拒绝恢复。分级不作为元数据可编辑项。

## 事务与撤销

每次管理以books.row_revision比较并交换；元数据、成员关系、移出标志与shelf_actions逆向快照同一SQL事务提交，批量最多100本（界面选择当前50本）。任一本已变化或SQL失败，整批回滚。最多保留最近20份撤销候选；重启仍可找到当前范围中修订匹配的最近候选。撤销验证当前修订、组仍有效及记录冲突后整批执行，不覆盖较新的阅读或编辑。它是受版本保护的单次撤销，不是无限多级历史回退。

LocalShelf将读写/封面请求纳入同一生命周期队列，dispose等待已经接受的请求，不再接受新请求；书架加载还带JobContext代际，旧请求不发布到新筛选或已锁定界面。

## 三种移除

- **移出书架**：只设books.deleted墓碑；文件、位置、笔记、标签和书籍身份保留。界面“已移出书架”可恢复，亦可撤销。
- **托管副本移入回收区**：仅应用托管的导入原件；先持久化file_recycle意图，再校验摘要并原子rename到recycle/摘要。目录或文件是符号链接、摘要损坏、目标冲突或其他书籍共享对象时拒绝。活动会话同步作废，引用模式从不进入这条移动流程。
- **移除个人记录**：用户另行确认后移除本书阅读/听书位置，将已有annotations标为删除；正文与书架保留。逆向快照支持撤销；若期间已有新位置或笔记版本，撤销整体停止。

恢复托管文件先写restore意图、校验并rename回objects，再清除意图；启动在取得单写入租约后续做未完成意图。失败保留意图与文件，详情允许重试或恢复；不会因失败删除恢复元数据。回收区仍占磁盘空间，本步没有永久清空、自动淘汰、磁盘配额或外部原件删除入口，未来MAC-14/22必须纳入该目录与日志。引用书签保留，不因移出书架而撤销原件授权；仍受原有权限恢复流程约束。

## 封面与隐私

macOS在现有DocumentBridge加入单选PNG/JPEG入口，返回同样的不透明只读FileGrant。调用端有4 MiB流读取限制，先核验最长边4096/8M像素，再解码单帧图，缩至最多384像素宽并保存PNG到独立covers/objects；动画、未知格式、解码失败和预算超限明确保留旧封面。书籍文件从不改写；不下载网络封面，无新增依赖。封面摘要随元数据快照撤销，未引用的旧封面留待后续可审计缓存管理，不宣称已释放空间。

分级检查同时覆盖列表、分组名称、详情、封面字节、修改、恢复和撤销；异步结果复查visibility代际。隐私锁作废活动会话，隐藏成人详情/标签/标题并驱逐已显示的内存封面；锁定不删除收藏。搜索18+开关不参与已有成人管理资格；生产库成年声明由用户自己确认。临时检查仅用自产中性材料和隔离目录。

本步没有完成笔记编辑、全文索引、下载/缓存配额、备份、来源接入、同步或其他三端验收。验证矩阵与实机证据见[MAC-08验收](../verifications/mac-08-2026-10-23.md)。
