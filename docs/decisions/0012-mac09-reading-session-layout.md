# ADR-0012：共享阅读会话、可重排视口与自动进度

日期：2026-10-26。范围：MAC-09，沿用D1、MAC-03位置协议及MAC-05/07文档端口；不扩展EPUB格式支持或加入在线来源。

## 决策

应用层的纯Dart ReadingCoordinator只持有一个前台ReadingSession。会话绑定book_id、文档修订和格式，保存当前DocumentAnchor、排版偏好、最多20条跳转历史与可见/暂停/专注状态。普通、菜单栏、阅读条、极简窗的表面标识接在同一对象上；后三种原生窗口仍由MAC-13实现。jumpTo接口检验修订，调用当前渲染器的导航回调，供MAC-10搜索结果复用，不是搜索已经实现。

ReadingPreferences区分全局默认和本书覆盖。schema8只新增reading_preferences，scope='*'为默认，其余为book_id；有版本的JSON限枚举、有限数值和区间。字号16–36、行高1.2–2.4、段距0–40、边距8–64、行宽360–1400；字体使用系统宋/黑/等宽与系统回退。正文主题可跟随应用、跟随系统或选暖纸/深色/护眼。损坏偏好回退默认、保留旧记录并提示，不能阻止阅读。

TXT保持按需读取最多8块，TextPainter只测量该窗口并及时dispose；逐行组成临时页片，页片只指向原块UTF-16区间，不创建新的内容修订。当前窗口的GlobalKey和页片随换块释放，双栏在视口不足720时回退单栏。重排前捕获内容锚点，重排后的程序性滚动不能替换为新的页首；过期的帧回调以代际丢弃。读完当前块窗口后通过下一页继续加载，不把整本书放入内存或生成全书页数。

EPUB继续使用受控WKWebView。新增固定的configure、viewport和page桥接操作；配置只接受白名单枚举/有限数值，回传仍与当前session/resource及规范正文核对。CSS列为临时页，当前章节之外不预排正文；视口宽度不足720回退单栏。自动位置使用可见字符点，与选区捕获分离。恢复及重排保留原字符，真实滚动/翻页才推进游标；窗口resize合并100ms，布局代际淘汰旧任务。字体就绪等待上限1500ms、帧等待有120ms后备，字体随后就绪会在仍有效的代际重排，避免后台窗口无限等待动画帧。8秒原生操作、10秒桥接及25秒首次就绪限时继续生效。

## 持久化与退出

前台观察最多每500ms合并一次写入，EPUB每700ms读取已核验的主机游标；相同锚点不重复落盘，来回滚动及已有写入进行中的最新位置也不能丢。保存队列按序执行，只写reading通道，沿用位置local_seq的CAS；旧会话finish后不接受回调，权限/清记录/回收作废会丢弃未提交候选。CAS失败暂停自动保存并保留旧记录，用户主动核对保存才读取最新序号重试，过时排队写入不越过新的确认代际。

切书/关闭会话排空已接受的候选；应用失焦、隐藏及正常退出请求主动flush，EPUB退出时额外取得当前主机锚点。系统强杀、断电或尚未送达应用的操作不承诺零损失；不持久化像素、页号或临时WebView会话ID。旧修订或上下文不匹配时自动保存暂停，旧位置由用户复核后才替换。

TXT目录浮层、正文和EPUB既有图片/目录浮层随访问代际隐藏；成年声明、搜索开关与隐私锁规则保持，来源仍0/0。

## 代价与保留边界

仅macOS arm64有构建及原生证据。受控EPUB继续有原有压缩包、资源、图片解码与会话预算；不为当前章节之外建立排版/字体/图像预取缓存。复杂竖排、固定版式、DRM、任意书内脚本不支持。TXT的按块继续和EPUB按章节估算进度不是全书排版页码；搜索结果的真实入口由MAC-10接入。无新依赖、正文同步、权限或外部请求。
