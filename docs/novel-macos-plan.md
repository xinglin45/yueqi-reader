# 阅栖小说 App：macOS 首批完整开发方案

日期：2026-10-15。状态：方案设计完成，功能尚未实现。使用方式已由用户确定为“先自用，通过安装包运行”。项目仍名“阅读软件”，小说 App 暂定名“阅栖”，漫画保持独立产品。

本轮已确认：小说只用中文资源（简繁），内置核验过的免费书源并支持导入；普通与18+在线来源都进入完整首版。搜索18+默认关闭，开启后才请求成人源；关闭开关仍保留独立分组中的已有成人收藏/阅读。以 [来源与18+搜索规则](novel-source-policy.md) 为准。

## 1. 本批目标与交付范围

先做一款能长期日常使用的 macOS 小说阅读器：从导入、整理、阅读、检索、做笔记、听书，到备份恢复形成完整闭环。使用 Flutter，保留 Windows、Android、iOS 的源码结构和平台接口。先交付 macOS，后续平台逐个验收，不能由 macOS 成功推断其他平台已可用。

本批先产出本方案、[任务拆分与验收](novel-macos-backlog.md)、[四端目录与技术边界](novel-cross-platform.md)，并推送仓库。实际开发按后续选择的任务推进，本轮不生成应用工程。

首批开发版本分两层，均在本方案中详设：

- **R1-A 本地能力内部检查点**：TXT/普通流式 EPUB、书架、目录/进度、排版、全文搜索、书签笔记、系统中文听书、备份恢复、统计、桌面交互、分级隐私与恢复能力。可出内部测试包，但单独完成不算本批首版交付。
- **R1-B 完整首版所需联网能力**：内置获准中文免费普通/18+来源＋自行导入、在线搜索/阅读、18+请求开关、REST/OPDS、下载/追更、有限基础规则与换源。R1-A＋R1-B全部通过才是完整首版；来源核验失败必须记录首版阻塞，不静默降级为仅本地阅读。
- **后续 R2**：可选共享账号/云同步、其他平台正式交付、PDF、复杂排版、AI 功能、完整规则脚本兼容等。本批设计扩展点，不将这些功能计为已实现。

R1-A 不要求登录、不要求联网、不要求部署 Java 服务。听书的离线能力取决于已安装语音和实机验证，不能承诺所有中文语音都离线或有相同音质。R1-B 不要求将正文代理到自有服务器。

## 2. 产品入口与界面组成

2026-10-16新增[独立视觉设计与原型确认](novel-macos-ui-design.md)（01A / MAC-02-D）：先产出视觉规范、主要页面和可点击原型，并取得用户明确确认的版本，再开始第02步MAC-02编码。下列布局是功能/结构基线，尚不是已确认的视觉稿；本次只添加环节，设计尚未开始。设计可使用普通占位内容提前进行，不等待来源核验或工程初始化完成。

桌面主界面采用可收起侧栏、内容区、必要时的右侧详情/笔记面板。窄窗口能切换为单栏；全屏/专注阅读隐藏非必要工具，移动端未来复用用例并另做紧凑布局。

| 页面/区域 | 用户能完成的事 |
|---|---|

| 继续阅读 | 最近阅读、上次章节/位置、正在听的书、未完成导入/下载提示 |
| 我的书架 | 网格/列表、合集/标签、未读/在读/读完、排序/筛选、批量管理 |

| 阅读工作区 | 正文、可收起目录、搜索结果、书签/笔记、进度与排版设置 |
| 听书面板 | 当前段/章节、语音、语速、暂停恢复、下一章、定时停止 |
| 搜索中心 | 书架元数据、当前书、已索引书库；联网来源搜索单独标明范围 |

全局始终可回到书架；详情、搜索、目录的跳转保存返回位置。空书架、正在解析、失败、无结果、权限不足、离线、分级锁定均有明确状态，不显示无限加载。

## 3. 功能清单与具体行为

下列 NM-Fxx 是本方案的功能追踪编号，与总需求文档互补。

### 3.1 启动、导入与书库

| ID | 范围 | 功能与边界 | 验收重点 |
|---|---|---|---|
| NM-F01 | R1-A | 启动/导航、最近阅读、书架入口、全局任务状态、重启恢复；欢迎页可跳过 | 新用户可直接导入；重启不丢已保存状态 |
| NM-F02 | R1-A | 文件选择、拖放、多文件/文件夹批量导入、格式识别、导入报告、进度和取消 | 单文件失败不终止整批；取消不留下半本“成功”书 |
| NM-F03 | R1-A | TXT 编码检测与手动纠正；候选 UTF-8/BOM、GB18030、Big5；预览解码结果再确认 | 中文简繁、换行、空白、错误编码可诊断；只声明库实测支持的编码 |
| NM-F04 | R1-A | 网格/列表、合集、标签、收藏、读完状态、手动/书名/作者/最近阅读排序、批量操作与撤销 | 筛选/排序重启保持；删除与移除书架区别清楚 |
| NM-F05 | R1-A | 编辑书名/作者/简介/语言、选择本地封面、同文件 hash 去重、相似书人工选择、文件来源信息 | 不以书名相同自动合并译本；不自动覆盖原文件 |
| NM-F06 | R1-A | 默认复制进应用托管书库；可选引用原位置，后者单独管理权限/文件变化/重新关联 | 原文件移动/权限失效有修复入口；引用模式不静默丢书 |

导入流水线：选择获准文件 → 探测格式/大小 → 安全检查 → 编码/结构解析 → 计算稳定内容身份 → 预览/去重 → 写入临时托管文件 → SQLite 事务登记 → 生成目录/索引任务。确认前原文件不被修改。失败清理临时文件，已导入部分可继续使用。

删除设计：移出书架、删除应用托管副本、删除笔记/进度是不同操作。默认不删外部原件；用户主动删除托管副本前展示影响，优先提供可恢复区。导入更新版本保留历史进度候选，不直接重置。

### 3.2 正文阅读与阅读记录

| ID | 范围 | 功能与边界 | 验收重点 |
|---|---|---|---|
| NM-F07 | R1-A | TXT 分章、章节规则预览/调整、无标题时按段落阅读、大书增量索引与渲染 | 不将整本大书同步解析在 UI 线程；目录可重新生成并保留可匹配锚点 |
| NM-F08 | R1-A | 普通 reflow EPUB、书名作者封面、spine/目录、内嵌图片与资源、章节链接 | 畸形、DRM、固定版式或不支持特性明确反馈；禁用远程脚本与危险资源 |
| NM-F09 | R1-A | 连续滚动/分页、单栏/桌面双栏、字号/字体/行距/段距/页边距/行宽、浅色/深色/护眼/跟随系统 | 变字号、缩放、窗口尺寸和模式后恢复内容锚点，不拿屏幕页码当永久位置 |
| NM-F10 | R1-A | 目录树、上一/下一章、跳章、阅读百分比、预计剩余时间、历史位置和返回、自动保存进度 | 明确已读进度与手动跳转；重启/崩溃恢复到最后成功保存锚点 |
| NM-F11 | R1-A | 当前书全文搜索、书库全文搜索、作者/标签/书名过滤、结果上下文/高亮、点击定位、取消/重建索引 | 中文简繁用真实分词/子串场景验证；不假设 SQLite 默认 tokenizer 自动解决所有 CJK 搜索 |
| NM-F12 | R1-A | 书签、文本选择、高亮、笔记、备注标签、笔记中心、导出 Markdown/JSON、回原文与修改/删除 | 原文修订后无法精确定位时保留摘录与提示，不静默丢笔记 |

阅读偏好分全局默认与单书覆盖；单书一键恢复默认。简繁转换、文本替换、过滤规则可作为显示层增强，默认不改原文；如开启，需要保存偏好并验证搜索/朗读与原始锚点的映射，映射不可靠则延期到 R1-B 增强。

内嵌图片可查看放大；EPUB CSS 使用可控支持集，作者样式与用户字号/配色的优先级明确。不要把“支持 EPUB”写成支持所有 EPUB 交互、DRM、排版与脚本。

预计时间/进度是估计；大书索引未完成时展示未就绪，避免伪造准确百分比。前台翻页/阅读变动及时持久化，后台批量写入可合并，具体持久化延迟预算见验收文档。

### 3.3 听书

**NM-F13 / R1-A**：优先适配 macOS 系统语音，保留可替换的跨平台 SpeechService。包含：

- 从当前阅读位置或选中文本起读；当前句/段高亮；暂停、继续、停止、上一/下一段。
- 到章节末自动衔接下一章，可关闭；切章/跳读/切书时取消旧队列，防止两路朗读同时播放。
- 语音与语言选择、语速、可支持时的音调/音量；展示系统实际可用语音，语音缺失给出设置入口/解释。
- 计时停止/本章结束停止；计时器使用可恢复状态，系统休眠/音频设备断开后保守暂停。
- 阅读进度与听书进度各自保存，用户切换时明确“接着听/接着读”的位置，避免自动互相覆盖。
- macOS 播放控制优先使用应用内快捷键；系统媒体键/后台控制作为能力验证项，通过后纳入，失败时有可用回退。
- 可选本地发音/替换规则在显示/朗读层处理；不改变书籍原文或未来云同步身份。
- 不默认上传全文到云语音。高级云语音/音频导出需单独核验服务费用、音色/作品许可和用户选择，列入后续。

Apple 的语音合成接口提供语音队列及播放控制；本项目的 Flutter 绑定、断句高亮、离线语音和长时间稳定性仍须验证，不能由接口存在直接判定功能已完成。

R1-B 的最小来源策略：优先核验中文维基文库、Gutendex中文作品、中文免费规则与OPDS渠道，见 [候选清单](data-sources.md)及[首轮实测](source-audit-2026-10-15.md)。维基文库仅单作品技术链路通过，整站分级/权利与实际App接入未完成；其他候选也未整体批准。没有获准来源时使用自产响应fixture验证行为，不把聚合规则当内置目录或最终来源验收。

普通和18+分别选择核验候选；青空文库等外文专属来源退出小说当前接入范围。内置可用来源与导入功能都必须完成；模拟响应只能验调度行为，不能替代完整首版的真实中文普通/18+来源验收。免费状态与分级分别记录，不自动购买作品、订阅接口或启用未知收费。

Legado 仅研究和实现经过测试的基础子集，支持矩阵列出 HTML/CSS/正则/分页等实际语义；不在 R1 承诺任意 JavaScript、登录脚本或完整兼容。来源认证只允许正常授权流程，敏感 Cookie/Token 保存在安全存储并与来源/账号绑定，不随规则导出。

本地备份包含个人书籍/摘录时，用户主动选择导出范围；默认只导出元数据和笔记，完整库只包含用户有权备份的内容。导出位置不默认放云目录；加密备份若实现必须有真实格式、密钥恢复提示和兼容性测试，不能仅改扩展名。

## 4. macOS 交互细则

建议默认快捷键（在快捷键服务中映射，未来 Windows 使用 Ctrl 等平台习惯）：

| 操作 | 建议快捷键/行为 |
|---|---|
| 导入文件 | Cmd+O；文件可拖入窗口 |
| 本书查找 | Cmd+F；全库搜索有独立入口 |
| 设置 | Cmd+, |
| 继续听/暂停 | 可配置，默认应用内 Space，输入框编辑时不抢键 |
| 翻页/章节 | 方向键/分页键；修饰键切章，最终键位由可用性测试确认 |
| 返回前一位置 | 可配置返回操作，目录/搜索跳转后可用 |
| 退出专注/关闭浮层 | Esc，按层级处理 |
| 标准编辑 | Cmd+C/A、文本选择与系统输入法正常工作 |

文件菜单、编辑菜单、阅读菜单、窗口菜单、帮助菜单按能力暴露。没有选中书/没有权限/不支持格式时菜单禁用并能解释。首次外部文件/目录访问使用系统授权，引用原文件时持久化安全范围书签；授权失效重新选择，不能请求全磁盘访问代替正常导入设计。

首批默认单主窗口，允许目录/笔记面板可收起。多窗口多书、复杂系统自动化、全局快捷键暂列后续，避免多实例写库和焦点问题挤占阅读稳定性。

## 5. 数据与平台设计要求

具体目录见 [novel-cross-platform.md](novel-cross-platform.md)。核心约束：

- 书籍 hash/源标识、章节身份、文本锚点、内容修订与笔记 ID 从第一版稳定建模，不能把 macOS 绝对路径作为跨端内容 ID。
- 数据库保存元数据、索引引用、状态；正文/EPUB/资源留在文件存储，普通缓存可清，用户导入原件与固定下载有独立保留策略。
- LibraryRepository、ReadingPosition、DocumentReader、SearchIndexer、SpeechService、FileAccess、SecureStore、WindowIntegration 等接口隔离平台和具体库。
- 以分批任务处理导入、索引、解析、备份；当前阅读优先，可取消并有内存预算；数据库单写入策略/事务边界明确。
- Flutter 只在 platform 适配层绑定 macOS 特有实现；公共领域/用例不直接引用 AppKit、系统路径或平台插件。
- SQLite 中文全文检索、EPUB 布局/锚点/选择/搜索/TTS兼容、系统 TTS 回调映射为前三项技术试验。
- SDK、数据库、状态管理、EPUB/TTS/文件库的精确版本在 MAC-01/06/12 中核验并锁定；本方案不虚构已选版本或四端兼容状态。

## 6. 开发阶段与发布门槛

| 阶段 | 本批结果 | 完成标志 |
|---|---|---|
| A0 技术底座与验证 | macOS优先四端边界、中文TXT/EPUB/搜索/TTS试验，同时前置普通/18+免费来源核验 | macOS基础壳与技术决策；真实来源可用性/许可风险在早期暴露，不能留到交付时才发现 |
| A1 本地阅读闭环 | 导入、书架、TXT/EPUB、目录/锚点/排版、基础分级锁定 | 断网可读、重启可恢复、文件问题可修复 |
| A2 日常本地能力检查点 | 中文全文搜索、书签笔记、听书、统计、设置、备份恢复、原生交互/可访问性 | 真实自用与故障场景可验收；仅R1-A内部检查，不计完整首版交付 |
| A3 首版联网必需能力 | 内置/导入、普通/18+免费来源、开关、下载、追更与显式换源 | 普通/18+真实来源各至少一条，开关请求级测试通过；缺任一类来源则首版仍阻塞 |
| A4 稳定性与安装包 | 性能/长书/迁移/恢复/权限/安全测试、版本化安装包、升级验证 | 用户能安装/升级/使用，已知问题有记录，源码/依赖/资源许可清楚 |
| R2 后续独立里程碑 | 可选云同步、Windows/Android/iOS、AI/PDF等 | 分开规划与验收，不计入本批 macOS 已交付功能 |

先以R1-A内部包验证本地能力，再合入R1-B形成首个完整可用macOS版本。开发逐任务验证，最终交付同时包含两部分，不把联网/18+来源推迟到首版以后。按 [任务状态](novel-macos-backlog.md)领取任务，依照 [详细开发步骤](novel-macos-implementation-steps.md)执行；环境前提见 [环境核验](development-environment.md)。

## 7. 第一批不强制实现的功能

- 付费/广告、内容商城、作者投稿、社交/评论、平台级海量版权内容运营。
- 任意 Legado JS、运行漫画 APK、抓取/绕过登录付费或年龄限制。
- PDF、扫描 OCR、固定版式 EPUB 全覆盖、外文专用排版。
- AI 翻译/摘要/人物关系、云端语音、网络全文上传。
- iCloud/WebDAV/自建服务等多种同步同时实现；先保留中立接口，确定需要后选一条路线。
- 自动安装更新、后台常驻追更、多窗口；可先提供手动版本检查与新包升级。
- 漫画客户端功能开发和手机/Windows 完整发行。目录与模型保留，不把它们删除或改成小说功能。

## 8. 验收原则与待定项

详见任务文档；先用自产中文简繁 TXT、最小 EPUB 与模拟来源完成自动验证。性能目标为设计预算，需要在实际基准机器上测量，不是当前性能承诺。

待开发前确定：最低 macOS 版本、Apple Silicon/Intel 支持范围、EPUB 引擎与原生插件、签名/公证条件。Flutter 当前官方 macOS 文档提示 Intel 支持在调整，不能在未选 SDK 时承诺通用 Intel 安装包。自用首批优先当前机器实际架构；对外分发再按当时 Apple 要求核验签名、公证与渠道。尚未购买证书或支付任何服务费用。

## 9. 官方技术依据与核验范围

以下只用于技术能力与约束；不构成第三方内容源/收费/商用授权核验。核验日期 2026-10-15。

- Flutter 支持单套源码与平台集成，四端工具链需分别准备：[平台集成](https://docs.flutter.dev/platform-integration)。
- macOS sandbox、entitlements、构建/分发和 Intel 提醒：[构建 macOS App](https://docs.flutter.dev/platform-integration/macos/building)。
- 用户选中文件、重启后引用文件的安全范围书签：[Apple 文件访问](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox)。
- 系统合成语音与控制回调：[Apple AVSpeechSynthesizer](https://developer.apple.com/documentation/avfaudio/avspeechsynthesizer)。

实际插件支持、操作系统行为、证书条件均仍要在本机及目标环境验证。来源各维度以独立核验记录为准，未取证的历史API/价格/授权继续待核验。flutter_tts的macOS暂停/语音标记能力有待专门试验，不能只因包声明支持macOS就假定功能齐全。
