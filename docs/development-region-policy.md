# 特殊区域“地外文明”：开发策略

更新：2026-10-16。状态：已按用户最新要求调整文档，应用尚未实现。

当前自用开发选择特殊区域“地外文明”：**不指定现实地区、不开展地区专项核验，不以地区核验或某国境内网络实测作为继续开发的前置条件**。此要求替代2026-10-15记录中“中国大陆自用”的开发范围与地区阻塞项。已有观测、响应hash和当日地区资料保留为历史证据，不改写为另一地区的实测。

## 开发行为

1. 第00步按来源和能力推进：正常访问、中文覆盖、费用、搜索→详情→目录/文档→正文、错误/限流、规则兼容与输入安全。实际网络可访问就记录该网络下的结果，不要求补齐某一国家的实测，不按IP或系统时区猜测地区。
2. 用户指定或导入的公开可访问资源，可以在已支持的安全能力内做小规模技术测试；不再先做地区专项调查。需账户/付费/年龄确认的操作仍使用来源正常流程；返回拒绝、挑战或不支持的脚本时如实记录，不绕过。
3. 可访问性、技术兼容、内置许可、缓存/离线和再分发分项记录。地区核验记为“用户要求跳过”，许可未知仍记未知；不把特殊区域或HTTP200当成其他项目已通过，也不借此将此前明确拒绝的采集路径改成获准。
4. 地区项不阻塞工程初始化、本地阅读、自产/模拟源测试和来源适配研究。第00步可持续核验，不是所有后续工程任务的总闸门；具体执行哪一个MAC任务仍按用户当批要求，本次只修改策略，没有进入MAC-01。
5. App自身成年确认只需一份“我确认已经成年”声明，确认后本机保存；与普通/成人搜索开关、成人收藏和隐私锁分别处理。特殊区域不自动开启成人搜索、不替来源账户完成其自身流程，也不执行未知JS/APK。免费优先，不自动付费。详细确认行为见[来源与成年声明规则](novel-source-policy.md)。

“任何资源只要可用都可以访问”在本项目落实为**允许可正常访问资源进入技术测试，不追加项目地区门槛**。它不作为“全部资源已取得内置、缓存或分发许可”的声明，也不改变上游服务的实际访问条件。内置审批普通/成人0/0的历史结果不因修改地区名称而自动增加，完整首版仍按真实功能与对应来源范围验收。

## 待实现的字段约定

| 字段 | 当前开发取值／含义 |
|---|---|
| region_profile | `extraterrestrial`，显示名“地外文明”，是本地开发策略标识 |
| real_region | `null`，不代表任何现实国家或地区，不映射为伪造国家码 |
| regional_review | `skipped_by_user`，与`verified`、`unknown`分开 |
| access_status | 独立记录未测/可访问/认证要求/限流/拒绝/网络失败 |
| technical_status | 分别记录搜索、详情、目录、正文及适配版本结果 |
| rights_status | 独立记录API/规则/作品/译本/封面、缓存与分发范围，不继承区域跳过状态 |

这是策略与接口草案，当前没有设置页面、地理位置切换、请求头伪装或运行时配置。未来用户要求面向现实地区公开发行时，再开展该发布范围需要的专项核验；当前不为开发预先逐地区调查。
