# 产品需求

状态：规划基线，功能尚未实现。优先级 P0＝本地 MVP 核心与接入门禁；P1＝可选在线/同步及扩展；P2＝后续探索。对应任务见 [roadmap.md](roadmap.md)。

## 产品范围

两款 App 各自拥有入口、安装标识、书架、本地库、阅读器与发布包；共享后端和基础包不合并 App。目标平台 Android、iOS、Windows、macOS。支持中文（简繁）、日文、韩文的文件、标题、内容与语言过滤；UI 本地化顺序待定，不默认引入自动翻译。

核心用户路径：

1. 用户不登录即可导入合法文件，进入独立书架，离线阅读、加书签，关闭后恢复位置。
2. 用户选择启用通过核验的来源，按语言/分级搜索，查看详情、目录，在线阅读并在许可范围内下载。
3. 用户主动开启同步，跨设备恢复个人书架、进度与书签；断网编辑下次联网重试。
4. 成人功能默认关闭；获准且满足来源、地区、渠道门槛后才能进入；拒绝后不泄露封面、标题或缓存。

## MVP 与非目标

本地 MVP：两款独立工程基础，小说 TXT/EPUB 与漫画 CBZ/ZIP 阅读、独立 SQLite、书架、书签、持久位置、缓存管理、中文日文韩文样本、分级模型与默认锁定。在线接入与同步是后续可选里程碑，接入时同样必须满足 P0 门禁。

当前不实现整个应用，不做大型正版内容平台、付费/广告系统、服务器代理全部内容、破解 DRM、登录/年龄验证绕过、完整第三方规则生态或任意 APK 执行。

性能目标将在实际设备基线测试后量化：记录冷启动、首屏、滚动帧、峰值内存和磁盘；不同设备不得套用尚无测试的数值。
