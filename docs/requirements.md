## 产品范围

2026-10-16 macOS小说UI交付流程：第02步MAC-02编码前增加独立任务[MAC-02-D / 01A视觉设计与原型确认](novel-macos-ui-design.md)，先交付具体视觉规范、主要页面和可点击原型，经用户明确确认版本后再编码；设计与功能完成分别记状态。设计可提前开展，不要求真实来源/后端或SDK就绪，当前D1暖纸设计与可点击原型已获用户明确确认，MAC-02-D/01A已完成，见[确认记录](design/novel-macos/confirmation-D1.md)；不算App实现。

两款 App 各自拥有入口、安装标识、书架、本地库、阅读器与发布包；共享后端和基础包不合并 App。目标平台 Android、iOS、Windows、macOS。小说资源只面向中文（简繁），界面、检索和听书优先中文；漫画仍支持中文/日文/韩文。共享模型保留语言标签，不默认引入自动翻译或小说外文源。

核心用户路径：

1. 用户不登录即可导入合法文件，进入独立书架，离线阅读、加书签，关闭后恢复位置。
2. 用户选择启用通过核验的来源，按语言/分级搜索，查看详情、目录，在线阅读并在许可范围内下载。
3. 用户主动开启同步，跨设备恢复个人书架、进度与书签；断网编辑下次联网重试。
4. 成人功能默认关闭；获准且满足来源、地区、渠道门槛后才能进入；拒绝后不泄露封面、标题或缓存。

## MVP 与非目标

全局本地能力：两款独立工程基础，小说 TXT/EPUB 与漫画 CBZ/ZIP 阅读、独立 SQLite、书架、书签、持久位置、缓存管理；小说使用中文简繁样本，漫画保留中日韩样本。小说联网产品范围包含免费普通与18+来源及默认关闭的搜索开关，来源需逐项核验；具体首版交付边界见macOS专题方案。

当前不实现整个应用，不做大型正版内容平台、付费/广告系统、服务器代理全部内容、破解 DRM、登录/年龄验证绕过、完整第三方规则生态或任意 APK 执行。

性能目标将在实际设备基线测试后量化：记录冷启动、首屏、滚动帧、峰值内存和磁盘；不同设备不得套用尚无测试的数值。
