## 通用完成标准

- 需求/任务 ID 可追踪，范围、依赖、真实交付物一致。
- 相应环境下可运行且有合理检查；平台、线上源或许可未验证明确标注。
- 离线/门禁/凭据/缓存/同步边界不被实现捷径破坏。
- 文档描述最终状态，而不是把将来计划写为当前能力。
- 未指定时间表、预算、来源价格或平台发布承诺。
