## 复现

在仓库根目录（可含中文与空格）：

```sh
python3 tool/sdk.py install
./tool/check.sh
cd 小说/client
../../tool/flutterw run -d macos --debug
# 退出Debug后构建Release
../../tool/flutterw build macos --release --no-pub
```

SDK默认放在用户工具目录，命令自身推导路径；如需指定已有SDK，使用YUEQI_FLUTTER_SDK，版本不符会拒绝运行。不得直接flutter upgrade；升级需显式修改pin、兼容记录和锁文件。SDK、缓存、构建产物不提交；本机Release产物在`小说/client/build/macos/Build/Products/Release/阅栖.app`。
