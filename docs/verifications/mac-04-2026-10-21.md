## 交付行为

系统多选、Finder拖放和系统文件打开共用导入预览；每批最多32项，TXT/EPUB原件各64 MiB上限。逐文件显示格式、大小、编码、标题预览、托管/引用模式及结果；普通/成人须主动分级，未分类不展示标题/正文预览、不允许提交。成年声明/搜索/隐私锁规则沿用MAC-16，没有地区核验或新身份要求。

托管默认复制原始字节到App资料区；引用创建本机只读安全范围书签，没有永久正文副本。原件不写入；引用授权过期/文件丢失可选择同摘要原件重新关联，内容改动要求新导入。状态入口重新核对完整摘要；托管副本损坏可重导同一原件修复而保留既有书籍记录。

TXT严格验证全文，支持UTF-8/BOM、UTF-16LE/BE；GB18030/Big5由用户选择后使用系统编解码往返核对，失败不替换字符。EPUB只验证有界ZIP/OCF、CRC、container/OPF/manifest/spine并提取标题，拒绝加密/字体混淆、ZIP64、多卷、外部实体、路径穿越和展开超限。详细限额见[ADR-0008](../decisions/0008-mac04-document-import.md)。

schema4→5增加imports（13表），保留旧样本、位置和设备声明。摘要相同复用原记录/分级，同名不同内容独立。暂存校验后提交元数据事务；失败清理本次暂存/新对象/新书签；取消只停止未提交项，已完成项保留。文件与SQL没有跨系统原子事务，崩溃孤儿不自动当作正文清除。

导入书籍使用通用文件图标，明确显示“文件已导入 · 阅读解析待接入”；点击为文件状态，不使用自产样本封面或正文伪装阅读。TXT与EPUB完整解析分别留在MAC-05/07。

## 自动化验证

`./tool/check.sh`通过：格式、客户端与三个共享包严格Dart分析、**55项Flutter/Dart测试**、**13项Python工具测试**。本批新增11项导入集成测试与2项界面测试；原存储/位置、门禁、导航与布局回归保留通过。

| 场景 | 实际验证与结果 |
|---|---|
| 托管/重复/同名 | 原字节一致、相同摘要只留一个ID、同名异内容两本；并发提交同文件无共享对象被误删 |
| 修复/只读/重启 | 丢失和损坏对象均可同摘要修复；自定标题/分级保留；chmod 0444的自产原件未改，移除后托管仍可用；启动只清旧暂存 |
| 中文编码 | UTF-8/BOM、UTF-16两端序及emoji严格检查；错误编码阻断，可显式重试；原生GB18030/Big5精确自产文字往返及坏字节拒绝，见[原生结果](mac-04/native-codec.json) |
| 引用 | 真实SQLite/文件＋授权替身重开恢复；过期/缺失阻断；同摘要重新关联替换旧授权，改变内容拒绝 |
| 门禁 | unknown不提交、成人须确认且解锁；搜索OFF不移出独立成人组；锁定后直接verify也阻断 |
| 异常/取消 | 流式取消、读取错误、不可用暂存目录、SQL触发器失败注入；无假完成记录、临时资源与新对象清理，原件不改 |
| EPUB输入 | 正常CRC/元数据通过，坏包、越界路径、DOCTYPE/ENTITY、加密标记、展开超限和非支持扩展拒绝 |
| 大小/句柄 | 动态64 MiB+1临时稀疏文件拒绝；流式读取退出后句柄关闭计数一致，无大文件入仓 |
| 界面批次 | 好坏混批逐项结果；未分级确认禁用，普通分级后显示预览；导入卡片无假封面；incoming共用预览且取消后无记录/暂存 |

磁盘不足使用故障注入，没有填满真实磁盘；授权过期/重新关联失败矩阵使用端口替身，不能扩大为系统所有文件提供器已通过。
