# 阅栖 · 01A交互原型 D1

独立React/Vite视觉原型。正式App继续采用Flutter，本目录不计作MAC-01/MAC-02实现。启动页复现第一套暖纸方向的阅读器与模式面板；从侧栏进入书架可体验完整主链路。

当前本机预览：http://127.0.0.1:4173/ （仅开发服务器运行期间可用）。

后续重新启动：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

验证：`npm run build`，`npm test`。`npm run test:sites`仅核验保留的模板托管适配，不表示本次已发布网站。

- 所有在线来源、导入/下载/备份/听书均模拟或状态预览；不访问第三方内容站点。
- 字体/模式偏好及一次成年声明保存在浏览器localStorage，可在设置→数据与隐私重置。书架、笔记、阅读位置仅当前页面内存，不代表SQLite、重启恢复或同步已实现。
- ⌥⌘R在网页获焦时隐藏/恢复；系统菜单栏、独立窗口、全局快捷键、Dock、置顶和穿透的macOS能力未实现。
- 原型说明提供空库/导入失败/文件丢失/权限不足入口。测试用“失败”搜索词触发模拟来源超时。
- 保留模板的Sites相关文件；本次未调用发布接口，也未公开托管。
