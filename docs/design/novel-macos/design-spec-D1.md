## 关键交互

1. **同一会话**：完整阅读、菜单栏、阅读条和极简窗共享chapter/paragraph。原型以段落索引演示，正式锚点仍需内容修订、字符偏移与上下文指纹。
2. **收起与恢复**：所有正文表面从页面卸载，关闭阅读相关浮层、暂停自动推进；恢复同一形态、段落、尺寸、位置与透明度，保持暂停。无提示音或隐藏成功toast。快速重复切换不创建重复表面。
3. **菜单栏**：默认只显示书本图标，不含书名。提供恢复/隐藏、三形态、完整阅读、设置、演示状态、退出。点击面板外只收起面板，不重置会话。
4. **悬浮表面**：默认不置顶、不穿透。拖动正文区域移动；按钮不触发拖动。悬停或键盘聚焦显示控制；纯正文不常驻书名/封面。
5. **自动行为**：鼠标离开且窗口无键盘焦点后，按选择延迟收起；默认关闭。原型支持定时按段推进，手动上一/下一段会暂停。隐藏后不推进；恢复后不自行播放。
6. **演示状态**：显式进入后隐藏，⌥⌘R与切换形态不能恢复；必须先显式结束演示，再主动恢复。不能把结束演示直接等同展示正文。
7. **穿透回退**：浏览器用pointer-events模拟当前浮层穿透，底部恢复入口和顶部菜单始终可用。真实App须在启用前确认可达的菜单恢复路径。
8. **排版/布局**：滚动与分页/双栏切换使用同一会话段落值；正式引擎还需验证字体变化/窗口缩放后的精确字符位置，原型不作为这项通过证据。
9. **成年声明**：原型本浏览器记忆一次声明，不收集生日、证件或实名；确认不自动开启搜索。搜索默认关闭，调度模拟器先排除18+源再计数；关闭开关后既有收藏保留，隐私锁另行控制。正式App按现有来源策略实施。

## 窗口与快捷键

| 项目 | D1设计 | 原型与真机边界 |
|---|---|---|
| 候选收起/恢复 | ⌥⌘R | 网页获焦时响应；未注册OS全局快捷键 |
| 返回完整阅读 | ⌥⌘F；面板按钮和菜单同样可达 | 演示状态禁止快捷恢复 |
| Esc | 关闭对话框/浮层/窄窗侧栏 | 非系统权限操作 |
| 菜单栏面板 | 300 × 380 | 浏览器内表面，非NSStatusItem |
| 阅读条 | 420 × 72，1/2/3行；字号变化同步调整高度 | 宽280–640，视口限宽；不是独立系统窗口 |
| 极简窗 | 420 × 280，可调高度180–480 | 同一页面中演示 |
| 多屏/Spaces | 记录屏幕ID与归一化位置，断屏后找回可见区域 | 原型仅有“显示器断开回退”中心位置演示；系统待验 |
| Dock/焦点/置顶 | 用户选项；不强制辅助功能权限才能读本地书 | 原型只记录选项；真实App待MAC-13/15 |
| 静默启动/唤醒 | 不因启动、唤醒、演示结束自动暴露正文 | 原型初始打开阅读页用于审阅；不证明原生生命周期通过 |

常规桌面按1487 × 1058对照；700 × 820检查窄窗口，390 × 844检查更紧凑布局；专注阅读可在“更多阅读操作”进入。紧凑布局不删业务功能，侧栏改抽屉，双栏回退单栏，浮层不超出视口。移动端实际触控目标、字体缩放与导航仍需MAC-26逐端设计和验收，不能把此网页截图算成四端完成。
