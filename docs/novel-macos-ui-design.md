## 设计范围与交付

先面向macOS小说App“阅栖”，项目显示名仍为“阅读软件”。功能以[完整方案](novel-macos-plan.md)为基线；四端业务边界和独立漫画App保持。当前不要求同时完成其他三端的高保真设计，但需要标注可复用组件和未来紧凑布局的适配原则。

| 交付 | 最小内容 | 确认重点 |
|---|---|---|
| 视觉方向 | 可比较的少量风格草案、主方向说明，收敛为一套方案 | 阅读氛围、信息密度、桌面交互与中文可读性 |
| 基础规范 | 明暗主题、阅读纸色、字体层级、色彩、间距、圆角、图标、焦点/选中/禁用状态，组件尺寸规则 | 控件与正文层级清楚，文字/状态可辨，后续页面能复用 |
| 主框架与页面 | 侧栏/内容区/辅助面板；书架、阅读器、在线搜书、来源中心、设置的主要高保真页面；任务/下载、笔记、统计的主要框架 | 导航、窗口空间分配、主要操作与返回路径 |

主窗口至少展示常规桌面宽度、窄窗口和全屏/专注阅读三种布局；覆盖明暗主题。设计中的字体、图标、封面示例记录来源和使用范围；使用自产或许可清楚的普通占位内容，不使用私人书籍、凭据或成人正文。制作工具在实际任务中选择，本次不预设Figma、图片工具或其他外部服务为必需依赖。

## 原型确认路径

1. 首次使用/空书架 → 导入预览与进度 → 加入书架 → 阅读 → 调整排版 → 返回并继续阅读。
2. 书架网格/列表 → 书籍详情/目录 → 阅读 → 搜索定位或笔记 → 返回原位置。
3. 在线搜书 → 来源状态/导入入口 → 搜索结果或无结果/错误 → 详情/目录 → 阅读；没有获准来源时展示真实空态，演示数据标明为模拟。
4. 首次受限操作 → 一份“我确认已经成年”声明 → 用户主动开启18+搜索；关闭搜索后已有成人收藏仍可从独立分组进入。声明不自动开搜索，隐私锁另有入口，确认逻辑以[来源策略](novel-source-policy.md)为准。
5. 设置/任务中心 → 调整偏好或查看进度 → 取消/重试 → 回到阅读；主要操作同时说明键盘焦点与快捷键入口。

原型只验证视觉、信息结构和交互，不证明真实搜索、下载、阅读引擎、TTS或数据持久化已实现。来源状态、成年声明与特殊区域策略不得因原型演示而被改写。
