# 小说资源、免费书源与18+搜索规则

更新日期：2026-10-15。状态：用户已确认的产品规则；来源清单尚待逐项核验，应用未实现。本文优先于旧计划中“联网可在首版以后加入”或“关闭搜索就锁定书架”的表述。

## 1. 用户已确认的范围

1. 小说只需要中文资源，默认包含简体与繁体；中文译文按中文内容处理，不因原作语言而排除。漫画中日韩范围不变。
2. 主要使用免费书源；内置经过核验的免费来源，同时允许用户自行导入来源。
3. 普通与18+来源都属于首版必需能力；不把“有18+开关但没有任何可用来源”视为完成。
4. includeAdultSources 默认 false，关闭时只搜索普通来源；用户打开后，普通来源和已启用的18+来源共同参与搜索。
5. 关闭搜索开关不移除、不隐藏或删除已收藏的18+作品：这些作品继续在独立分组管理，按已有访问权限阅读。搜索开关只控制在线发现/搜索范围。
6. 首个正式可用的 macOS 版本必须同时通过在线搜书、阅读、普通/18+来源和开关验收；只有本地阅读的版本仅是内部检查点。
7. 当前先自用、通过安装包运行；不引入广告/支付/强制登录。收费内容/需付费接口不默认启用或产生费用。

## 2. 来源接入

- 内置目录只包含已核验且符合当前自用模式的中文免费来源，显示普通/18+分类、免费状态、版本、能力与最近核验信息。
- 支持导入本项目公开定义的来源描述、标准适配配置及经声明支持的 Legado 基础子集；规则能导入不代表所有字段、JS、登录脚本都能执行。
- 导入前预览域名/分类/权限/格式和支持情况；未知授权/未知分级/未知执行能力不静默获准，用户可以保留为待检查条目。
- 来源分类至少有 normal/adult/mixed/unknown；费用与分级分别建模，不能认为成人必收费或免费必普通。
- 普通和18+来源都可独立启停；搜索开关打开不自动启用所有成人来源，也不替用户完成来源登录/自身年龄条件。
- 书源版本、目标站能力和可用性各自记录。内置条目更新展示差异，不静默扩大域名、执行权限或收费范围。

免费状态记录 free/limited_free/paid/unknown、登录要求、额度/超额行为与证据。首版优先 free 或已知不会自动扣费的免费额度；未知收费不自动消费，付费来源仅留模型扩展，不是首版推荐路径。

## 3. 搜索调度

每次搜索创建 request_id、查询参数和搜索设置快照，再选择有效来源，不先请求全部来源再隐藏成人结果。

| 场景 | 可以发出的请求 | 用户可见结果 |
|---|---|---|
| 开关关闭（默认） | 已启用、核验通过的中文普通来源 | 普通结果 |
| 开关开启 | 上述普通来源，以及已启用且获准访问的中文18+来源 | 普通/18+结果明确标记，可分组筛选 |
| mixed来源支持可靠普通筛选 | 关闭时只使用已验证的普通查询路径 | 仅普通作品 |
| mixed来源不能可靠限制、或来源分类unknown | 不纳入默认普通搜索 | 待确认分类后再决定；不能将unknown当normal |
| 搜索中打开开关 | 给当前查询添加获准成人来源，或按清晰提示重新搜索 | 旧普通结果可保留，去重不抹掉来源标记 |
| 搜索中关闭开关 | 取消成人来源在途请求，丢弃迟到回调并停止成人发现分页/预取 | 移除当前在线成人结果/摘录，不删除书架收藏 |

建议的调度条件：来源已启用、核验/访问状态满足、包含中文内容，且 source_mode=normal 或 includeAdultSources 明确允许的 adult/mixed 请求。

对缓存结果、搜索建议、在线历史推荐和迟到响应应用同一搜索设置版本。测试必须检查关闭状态下成人 mock endpoint 收到 **零请求**，不能只断言 UI 没有成人卡片。

开关关闭时不主动向成人来源执行在线发现/排行/自动补搜/普通健康探测；用户从已收藏作品主动阅读、下载或检查所收藏作品更新属于独立显式操作，按该作品访问策略执行，不因搜索开关关闭而强制中断。

## 4. 收藏、阅读与隐私分离

- 成人书架是独立分组，仍保存阅读进度、书签、笔记和下载状态；不在首页普通推荐中混入。
- 关闭搜索开关后，用户仍能在该分组继续阅读已有作品；不开启新作品成人在线搜索。
- 用户主动从分组筛选本地已收藏元数据，不等于向成人来源发起在线搜索；界面需明确“本地书架”与“在线找书”范围。
- 隐私锁、来源自身的年龄/登录条件和搜索开关是不同策略。明确锁定隐私模式或资格失效时，受保护阅读/预览/TTS按门禁处理；搜索开关本身不是隐私锁。
- 不通过开关绕过来源付费/登录/年龄访问控制。自用版本不额外假定必须接入第三方实名服务；启用提示与本地设置遵循当前产品范围，未来公开发行再核验适用要求。
- 设置重置/新安装时开关默认false；不从云端/备份静默开启其他设备的成人搜索偏好。不把未知分级自动当普通。

## 5. 首版交付门槛

除本地功能外，下列全部属于 R1 完整首版验收：

1. 至少一条核验通过的中文普通免费来源，实现真实搜索 → 详情 → 目录/文档 → 阅读。
2. 至少一条核验通过的中文18+免费来源，实现对应路径；来源可以共享某平台的不同已验证分区，但要能独立限制请求。
3. 关闭/开启/搜索中关闭开关的请求次数、结果过滤、取消与迟到响应测试。
4. 已收藏18+作品独立分组；关闭搜索后收藏/进度/阅读能力保留。
5. 内置来源与自行导入均有获准样本、版本和支持矩阵，未知脚本不执行。
6. 网络失败/限流/来源失效/缓存/下载/署名处理按已有方案验收。

未找到可用且满足条件的普通或成人来源时，标记 MAC-18/19 等任务外部阻塞；不能用模拟响应代替最终来源可用性验收，不能将仅本地安装包称为已完成本批首版。模拟响应只验证可控行为，不证明真实内容权限和稳定性。

2026-10-15已开始[首轮来源核验](source-audit-2026-10-15.md)，仅有局部技术/资料证据，没有获准内置来源或价格承诺。候选继续见 [data-sources.md](data-sources.md)，各维度按独立记录判断。
