# reader_core

MAC-01已初始化的纯Dart共享包，当前仅提供ReaderProduct的小说/漫画独立命名空间，并由小说基础壳实际引用。无外部依赖，不导入Flutter、dart:io或任一App，不推断系统目录；不包含阅读引擎。

ID、语言、分级、分页和错误值在真正使用它们的FND/AGE任务再按需实现，本包不声称这些已有功能。当前用应用侧架构测试检查共享包依赖边界与两产品隔离；公共包无单独锁文件，使用客户端锁文件解析。

验证：仓库根 `./tool/check.sh`。说明见[MAC-01记录](../../docs/verifications/mac-01-2026-10-16.md)。项目源码许可证尚未选定。
